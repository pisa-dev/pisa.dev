Durante il talk verranno illustrati:
- Differenze architetturali tra applicazioni backend classiche rispetto allo sviluppo serverless
- Architettura di un'applicazione serverless
- Introduzione al CDK (Cloud Development Kit)
- Demo di un API serverless
- Spiegazione del codice sviluppato

L'evento sarà di tipo **live coding**, lo speaker illustrerà interattivamente il codice man mano che lo sviluppa. Pur non essendo un workshop, i partecipanti potranno seguire portandosi un proprio computer con un account AWS (e aws-cli) già configurata e pronta all'uso.

## Conoscenze richieste

Per seguire questo evento non sono richieste particolari conoscenze. Alcuni concetti basilari del funzionamento di API HTTP e database saranno dati per scontati.
