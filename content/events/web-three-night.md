# Talks

## Prepare your 🚀: we are going into Cosmos

Cosmos SDK è il framework più utilizzato per costruire blockchain. Il protocollo IBC permette a tutte queste blockchain di scambiare dati tra di loro, creando la visione dell’”internet delle blockchain".
Durante il talk creeremo una blockchain per una piattaforma di blogging, e useremo IBC per salvare i post anche su una seconda blockchain.

~ Antonio Pitasi - Blockchain Engineer @ Qredo

## Intro a IPFS: Interplanetary File System

IPFS è un innovativo protocollo di storage e retrieval di dati con architettura peer-to-peer. In questo tutorial lampo scopriamo insieme a che cosa serve, che vantaggi offre rispetto a soluzioni centralizzate, e come si usa.

~ Filippo Costa - Rust Software Engineer @ Edge & Node
