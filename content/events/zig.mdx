Zig è un linguaggio di programmazione moderno che punta a sostituire C come linguaggio di sistema. In questo talk esploreremo le caratteristiche che lo rendono unico e vedremo come si confronta con Rust e Go.

## Cosa imparerai

- Come funziona la gestione della memoria in Zig
- Il sistema di build integrato
- Interoperabilità con C
- Quando usare Zig al posto di altri linguaggi

## A chi è rivolto

Questo evento è adatto a sviluppatori con esperienza in linguaggi di sistema o chiunque sia curioso di esplorare nuovi linguaggi di programmazione.
